# A06 reproducibility records

This folder owns sanitized self-hashed A06 evidence, each within the 1 MiB reader limit.

- `pilot.json` records the development-only native-original cost pilot and retained grid.
- `demo-selection.json` fixes the substitute source/crop before catalogue rankings.
- `known-target.json` records generated diagnostic truth and independently expected maps.
- `final-check.json` binds the unchanged original A05 choice/shortlist, authoritative
  protocol/suite, representation/checkpoint, split/grid, committed implementation and
  environment before inference. It leaves `manifests/matchers/choice.json` at stage A05.
- `final-results.json` records the one final controlled check, condition/family counts,
  misses, absent distributions and costs. It is independent of real-song relevance.

Originals, weights, shards/indexes, queries/predictions, ledgers, private paths, exported
clips and HTML bundles remain ignored. Public records document delivery evidence;
they do not restore ignored assets or prove readiness on another machine.
