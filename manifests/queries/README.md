`integration.json` declares narrow shared hooks and historical read-only boundaries.

independent support/truth checks, frozen methods/denominators and producing code
before matcher/pitch comparisons. `real-demonstration.json` predetermines real bounds,
cue reuse and the pitch settings. `loulou-availability.json` separately records the
new supplied file's A02 technical availability while preserving the initial reference
manifest and B02's historically correct missing-input statement.

namespaces. Earlier evidence remains immutable. Public records do not supply media,
model weights or local availability in another checkout.
