# B01 traceability

This folder owns public event-selection declarations and sanitized delivery evidence.
Private audio, features, mutable progress, compatibility receipts and playable bundles
remain in the ignored delivery checkout under `data/` and `reports/local/b01/`.

- `integration.json` retains original shared-function source proofs from the A06 commit;
  the historical repair/declaration/index are separately hard pinned by the consumer.
- `development.json` freezes the ten development cases, one settings configuration,
  selection/default rules, note/retrieval metrics, tolerances and stop rule before scores.

Neither file authorizes A06 inference or changes its historical recipes or results.
See [B01 contracts and commands](../../docs/EVENTS.md).
