# B01 traceability

This folder owns public event-selection declarations and sanitized delivery evidence.
Private audio, features, mutable progress, compatibility receipts and playable bundles
remain in the ignored delivery checkout under `data/` and `reports/local/b01/`.

- `integration.json` retains original shared-function source proofs from the A06 commit;
  the historical repair/declaration/index are separately hard pinned by the consumer.
- `development.json` freezes the ten development cases, one settings configuration,
  selection/default rules, note/retrieval metrics, tolerances and stop rule before scores.
- `boundary-audit-plan.json` declares the saved-result insertion-offset correction,
  invalid oracle handling and partial evaluation without another model query.
- `accounting-audit-plan.json` declares the additional root-validation read charge;
  old ledgers and prior B01 charges remain intact.
- `results.json` retains corrected boundaries, fixed-pool retrieval strata/K values,
  invalid oracle handling, native crops, both catalogue ranks, query reuse and playback.
- `resources.json` retains finite ceilings/charges, consumer receipts, observed memory,
  failures and separate validation costs.
- `preservation.json` binds the private before/after audit of earlier byte/size/mtime identities.
- `commands.json` lists exercised bounded commands and producing-code/resumption caveats.

Neither file authorizes A06 inference or changes its historical recipes or results.
See [B01 contracts and commands](../../docs/EVENTS.md).
