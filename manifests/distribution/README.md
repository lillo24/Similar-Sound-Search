# D03 distribution declarations

`consumer.json` pins the exact installed core, D03 adapter and UI source maps,
inherited numerical hash, narrow changed interfaces and accepted prior consumers.
The declaration script verifies unchanged AST outside those interfaces. Retained
predecessors in `consumers/` preserve prospective drafts and the paid Windows
persistence/HTTP repairs. The corresponding application consumer archives permit
strict resumed-producer inspection without rewriting older declarations.

`dependencies.json` lists the complete 18 pinned dependency wheel identities,
hashes and expanded sizes. The archive's `release.json` additionally inventories
the actual application wheel, public configuration, notices and setup entry.
Neither record contains cache locations, private audio, a checkpoint, an allocation
registry or runtime state. Those remain separately inventoried private prerequisites.
