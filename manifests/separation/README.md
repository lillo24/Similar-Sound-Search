# B02 evidence map

This folder owns prospective B02 policy/integration/protocol and sanitized delivery
evidence. Private signals, feature arrays, worker ledgers and playback bundles live
under `data/runs/separation`, `data/features/separation`, and `reports/local/b02`.
Historical A03–B01 artifacts are inputs and remain immutable.

`policy.json` is committed before feasibility processing. `integration.json` records
the narrow shared boundary extension before implementation. The development plan
and independently checked geometry will be committed before comparison inference.
