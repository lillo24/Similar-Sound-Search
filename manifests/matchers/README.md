# Frozen development comparison records

This folder connects the prospective geometry correction, representations, model sources, development results and provisional A06 handoff. Audio, checkpoints, feature arrays, complete predictions/scores, progress and ledgers remain ignored.

- `geometry-before.json` preserves the original A04 geometry, actual constant/seeded control scorer results and analytical random expectations before candidate rankings.
- `checkpoint.json` records bounded official release acquisition and its observed/pinned checksum. Reuse validates the exact bytes.
- `shortlist.json` freezes two representation descriptors, code/checkpoint/tool identities, preprocessing/distance/grid and explicit unavailable alternatives before model ranking.
- `comparison.json` gives per-condition/per-family development metrics, denominators, costs and control comparisons.
- `choice.json` binds the provisional method/configuration, protocol/suite, shortlist, development runs, exclusions and limits. Its stage is **A05**, not permission to bypass the A06 held-out guard.

Each self-hashed JSON obeys the 1 MiB reader contract. [Evaluation records](../evaluation/README.md) retain unchanged audio recipes, source families, target truth and the atomic paired protocol/suite revision.
