## 2. Propose complete event intervals

Provide a bounded command accepting an explicit source/parent record and a selected region. For a verified full-track Loulou source, use the marked region; for an existing excerpt, use its actual available-file coordinates and known offset evidence. Otherwise use a clearly labelled substitute chosen before examining its search results. Keep an explicit manual interval path usable without requesting manual work from Leonardo during B01.

Implement a deterministic CPU event proposer using the installed NumPy/SciPy stack where practical. A small combination of onset novelty and envelope/energy evidence is a reasonable starting point; document the actual algorithm, analysis channel policy, frame/hop, thresholds, hysteresis, minimum duration/gap and finite event count. Bound any development comparison to a small predeclared shortlist of settings. No new learned detector or separation dependency is necessary.

The proposer must preserve a sound's own evolution:

- Include the attack leading into an onset and a justified release/decay tail. Do not make every onset-to-next-onset segment a complete note: adjacent attacks may occur before the preceding decay ends. Allow overlapping proposed intervals where warranted and identify unresolved overlap/continuous activity.
- Treat short transients, slow attacks, sustained tones, vibrato/modulation, noise-like events, close repeated notes and mixed accompaniment explicitly. An energy threshold alone must not silently erase quiet attacks or tails. Distinguish an intentionally sustained interval from an event whose end was not observed.
- Analyse channels without accidental phase-cancellation blindness; preserve the original channel policy for extracted audio. Any analysis downmix/resampling needs a documented source-frame mapping and a stereo cancellation fixture.
- Keep proposals inside the authorized source/region. If extra available context is used, bound and record it. Flag events cut by a file/selection edge or duration cap; never silently trim them and mark them complete. Return an explicit empty/uncertain result when no defensible event is found. A separately labelled whole-region fallback is permissible; it is not detected-note success.
- Store measured evidence or heuristic confidence with its meaning. It is not a calibrated probability, an instrument label, confirmation of Leonardo's intended layer, or proof of perceptual similarity. In polyphonic audio, a proposed crop still contains its surrounding layers; isolation belongs to B02.

Retain a deterministic, bounded ordering and stable event IDs. Separate proposal generation from selection. An explicit list of IDs or intervals must reproduce exactly the selected set; automatic selection must record its rule and cannot use downstream retrieval scores, filenames or hidden truth to choose convenient events. Do not force multiple examples to be the same sound when the source does not establish that.
