## 1. Define the new index boundary

Inspect `search/index.py`, `contracts.py`, `sources.py`, `ranking.py`; `events/compatibility.py`; `queries/context.py`, `materialization.py`, `execution.py`, `features.py`; and `separation/artifacts.py` before choosing interfaces. Add one small indexing owner and source map. Compose existing decoding, representation, source validation, integer-grid and array primitives where their contracts fit. Document necessary shared-interface changes explicitly instead of duplicating the pipeline.

Define a **bank** as one declared signal variant, representation, window duration and hop policy. Keep different banks separately addressable. A versioned index snapshot references their actual source/shard membership and coverage; it is not merely a directory of unlabelled vectors. Separate immutable plans/snapshots from mutable progress. A snapshot must identify the exact committed row set, including whether coverage is partial.

| Record | Required meaning |
| --- | --- |
| Source | Original recording/group and source-record hash; byte/PCM identity, decoder, native rate/channels/frames, provenance and available-file/master mapping. Generated evaluation data stays outside the discovery catalogue. |
| Signal variant | Original or a specific processed component; full transformation/configuration/code/output identity, original support, mapping and parent/cue ancestry. A component is not a new recording or a verified instrument. |
| Bank | Representation/checkpoint/preprocessing, duration/hop/rounding/tail policy, signal variant, intended source population and readiness/default/experimental status. |
| Passage | Stable row identity, bank/source/component, exact integer half-open native bounds, actual analyzed support, feature shard/row and original playback mapping. Padding/context is not scored source support. |
| Snapshot and coverage | Intended versus committed membership; per-bank/source states, counts, gaps, exclusions and failures; source/group and shard hashes. Overall state cannot hide an incomplete optional bank. |

Use bounded float32 shards, explicit shapes/dimensions and integrity checks; avoid a separate file per overlapping window. At most 512 rows per shared array bundle remains supported. Preserve the frozen embedding and distance semantics, including short-input handling. No new representation, learned calibration, ANN dependency or database service is required.

Hash the dependencies that change samples/features and preserve their producing versions. Display labels, runtime timing or unrelated coordinator edits must not masquerade as changed audio. Reuse still needs a separately validated consumer/code binding. Reject corrupt, stale, mismapped or incompatible artifacts visibly; do not regenerate over historical evidence or accept a file solely because its name/shape matches.

## 4. Support components without promoting failed separation

B02 did not justify automatic catalogue-wide separation. Keep original-only indexing as the default and **do not separate the entire catalogue** in C01. Exercise the component-bank contract on a controlled mixture and at most four prospectively selected real regions, reusing validated existing B02 query-independent outputs where available. This is bounded engineering evidence, not a new claim that separation improves relevance. Report component coverage as partial/experimental and distinguish it from full original coverage.

Only genuinely query-independent representations belong in a reusable generic component bank. HPSS harmonic/percussive outputs must carry their actual names and limitations, not instrument labels. Guided output conditioned on a particular cue is query-dependent: refuse it as a universal catalogue stem and retain that work for C03. Determine dependency from the actual transformation inputs/method; do not strip cue provenance merely to obtain a reusable key. Existing processed query revisions remain usable as queries under their explicit semantics.

Bind input/parent/configuration/DSP versions, region, padding/trim/delay/gain, output hash, channels/rate, mapping and all ancestry through each component passage. Respect B02's native allocation and twelve-second context limits. A context-sized component is not a full-track stem. Index only actual supported samples, and never span discontinuities by concatenating unrelated processed regions. C01 does not need a new long-track separator/chunking algorithm or learned checkpoint.

Check nonfinite output, clipping, near-silence, missing components and map integrity before admission. Retain failed/unsupported planned units in coverage with explicit reasons; do not replace their vectors with zero or quietly switch to original. When examining an indexed component hit, play its corresponding **original mixture** with truthful timestamps; optional component audition must be separately labelled. Reconstruction or a cleaner-sounding waveform alone is not a retrieval promotion gate.
