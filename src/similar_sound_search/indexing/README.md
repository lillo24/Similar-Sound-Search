# C01 indexing owner

| File | Responsibility |
| --- | --- |
| `context.py` | Fixed ceilings, owned roots/publication, one model per worker, read-only B03 view and explicit owned derivative |
| `banks.py` | Semantic bank/sample/row identities, immutable plans, native-to-original maps and interval-union coverage |
| `build.py` | Pending units, atomic shared arrays then membership, visible failures, bounded resume and charged reuse |
| `reader.py` | Fresh audited A06 references, C01 row/array reading and immutable multi-bank snapshots |
| `queries.py` | Load an exact revision/materialization; explicitly import/materialize a missing derivative into C01 |
| `components.py` | Validate B02 region components, actual cue dependency, maps, ancestry and experimental status |
| `development.py` | Fixed generated development assets and one separate-bank source-consistency comparison |
| `validation.py` | Independent native WAV/FFT geometry, scalar/grid/winner oracles and prospective cost/support admission |
| `ranking.py` | Mean-example exact search per bank, exclusions, complete group winners and original-bank equivalence |
| `commands.py` | Metadata preflight, Windows commit-memory measurement and explicit CLI routing |
| `job.py` | One cumulative offline ledger, hard worker deadlines, single-writer lock and inclusive process timing |
| `report.py` | Separate candidate lists, original-mixture playback, labelled component audition and native sample verification |

Shared grid/array, decoding, frozen representation, B02 validation and saved-query
recipe boundaries retain their owners. The only shared feature hook is
`owner.feature_root` in B03's cache; its default and semantic key are unchanged.
Plans pin producer code separately from sample dependencies. Snapshots pin exact
committed membership. A bank policy ID alone does not identify a population;
consumers must use the snapshot/bank-record hash and row identity together.
Generated controls are referenced outside discovery coverage. C02 owns any
cross-bank/event combination, calibration, shortlist policy and hit aggregation.
