# D02 evaluation owner

This package owns a finite, reproducible generated-population evaluation. It is
separate from the historical product source map; its own exact consumer pins every
Python file here. No generator family or ground-truth label enters retrieval.

| File | Responsibility |
| --- | --- |
| `commands.py`, `__main__.py` | Explicit preflight, generate/audit, index, query, run/resume, score, report and local serve commands |
| `context.py` | Genuine D02 roots/pool and packed-group reads, using the application's protected accounting machinery |
| `budget.py` | Fresh complete managed-tree scans with cached directory-entry sizes, preserving caps and link exclusions on Windows |
| `contracts.py` | Exact inherited/own code proof, neutral inputs, population checks and finite execution claims |
| `dataset.py`, `rendering.py` | Frozen independent performances, original bytes, genuine source metadata and B03 reference recipes |
| `audit.py` | Independent mixture algebra, emitted PCM/native geometry and isolated relevance truth |
| `pipeline.py` | Production model/cache/score/fusion calls and immutable complete predictions |
| `runtime.py` | Trusted provider for the existing import/save/submit/status/result/media HTTP API |
| `jobs.py` | Serial actual-PID workers, native QA, useful-unit commits, cancellation and protected settlement |
| `scoring.py` | Saved-prediction validation, group/event metrics, paired gate and diagnostic controls |
| `report.py` | Private per-case playable report and immutable own-root allowlist |

The production seams are limited to five application files: trusted provider
selection in API/server; model sharing and genuine ancestry in the query adapter;
exact scoped compatibility in history; actual job IDs for prepaid-stage attempts
in context. DSP, model, grids, distances, consolidation and rank fusion stay in
their existing owners. Report/scoring never encode audio or call a matcher.
